# Federal Reserve policy-release corpus v11

Board-authored information is public domain unless otherwise indicated; cite the
Board. See https://www.federalreserve.gov/disclaimer.htm. This derivative contains
text only and excludes seals, logos, images and linked third-party works.

The package is an outcome-blind corpus artifact, not an official Board product,
not a historical-availability certification and not a predictive result. IDs,
timestamps and categories are audit metadata; only text may enter a future LLM.
Pages sharing one release timestamp must be grouped as one event before evaluation.
