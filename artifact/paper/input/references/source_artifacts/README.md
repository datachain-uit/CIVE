# Verified reference artifacts

This directory stores machine-readable metadata and publisher-page snapshots for sources used by the thesis. Files prove bibliographic identity and provenance; they do not imply access to subscription-only full text.

- `crossref/`: Crossref metadata captured by DOI.
- `datacite/`: DataCite metadata for datasets.
- `publisher/`: official publisher, dataset, API-documentation, and lawful working-paper snapshots.
- `manifest.csv`: local path, source identifier, retrieval date, SHA-256, and file size.

The NBER working-paper PDF for T18 is archived as the accessible full-text precursor to the 2026 Mathematical Finance version. Cite the journal DOI in the thesis; use the NBER file only as the local source artifact.
